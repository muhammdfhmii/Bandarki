# Bandarku

A city-building game in a single HTML file. Works offline.

## How to play offline

- **Easiest:** download `index.html` and open it in your browser.
- **Like an app:** turn on GitHub Pages (Settings > Pages > Branch: main), open the link once while online, then choose "Add to Home Screen". After that it opens without internet.

Your city is saved automatically on your own phone / browser.
